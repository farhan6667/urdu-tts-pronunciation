# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and respect every language, accent and dialect. Don't post other people's voice recordings without their consent.

Report problems privately to the maintainer through a GitHub security advisory, or by email at nexaforge.services@gmail.com.
